# 裁板計算

把「生產料單」PDF 拖進網頁，自動算出每個顏色、厚度要開幾片大板，以及 A／P 封邊條各要多長。

所有計算都在使用者自己的瀏覽器裡完成，料單不會上傳到任何地方。

## 使用方式

1. 打開網頁，按「選擇 PDF 檔」或把料單 PDF 拖進來
2. 選大板規格（預設規格 4：2420 × 1210，會記住）
3. 看結果表；需要的話點開排版圖、按「列印」

讀到的總片數會自動跟料單上的「片數總計」核對，對不上會用橘色提醒。

## 計算規則

- 每片料件長、寬各加 10mm（耗材）
- 料件的「長」一律對大板的「長」（紋路方向，不旋轉）
- 只用一刀到底（guillotine）的切法；多種排法都試過，取用板最少的結果
- 封邊：寬欄的代碼封長邊、長欄的代碼封寬邊，每邊加 30mm
  - 例：線板 2400×80，寬欄 1A，數量 4 → A 封邊 (2400+30)×4 = 9.72 米
- 封邊依「顏色 × 厚度 × A／P」分開加總
- 耗材、封邊加長、修邊、四種大板尺寸都可以在「設定」裡改

## 開發

```bash
npm install
npm test
```

- `js/core.js`：解析料單、排版、封邊（瀏覽器與 Node 共用）
- `js/app.js`：畫面
- `vendor/pdfjs/`：pdf.js 3.11.174（legacy build）
- `test/local-*.test.js`：用實際料單 PDF 的端對端測試。料單與這些測試含訂單資料，已被 `.gitignore` 排除，只留在本機。

本機預覽：`python -m http.server 8781`，再開 `http://localhost:8781/?sample=裁板料單.pdf`（`sample` 參數只在 localhost 生效）。
